# Hero Scenario

Customer operations is a demo package proving the horizontal runtime. It must not define kernel semantics.

The eventual synthetic scenario stages schedule, attendee-message, and follow-up changes across reference adapters. Protecting one sensitive resource becomes a structured replay constraint; a clean replay removes that resource's entire causal effect group while provider fixtures remain unchanged before approval.

Gate 4 implements the synthetic Acme and Globex replay proof in
`@preview/customer-ops-demo`. Revision 1 stages Calendar, attendee Mail, and CRM
follow-up effects. Protecting the Acme Calendar event creates a constrained
revision on the same base snapshot and removes the complete Acme causal group
without mutating any provider fixture.
